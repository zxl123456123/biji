## 0.8.0 当前体验版 · 2026-10-06

本版将记录年轮、待办、自绘标题栏及现有记录、账本、关联图、记录时光、伙伴能力收敛到同一份 Windows 构建。可使用[程序 EXE](src-tauri/target/deliveries/0.8.0-release/qingjian.exe)、[NSIS 安装包](src-tauri/target/deliveries/0.8.0-release/晴笺_0.8.0_x64-setup.exe)或[MSI](src-tauri/target/deliveries/0.8.0-release/晴笺_0.8.0_x64_zh-CN.msi)；这些制品保存在本机忽略目录，不随 Git 推送。[0.8.0 验证记录](docs/Release.Verification.0.8.0.md)列出来源、哈希、已测和未测。

记录卡片的日历按钮可打开可选的「记录年轮」宽幅覆盖层：以这条记录的创建年份展示真实十二个月和有效日期，点击日期查看当日全部未删除记录，再进入原编辑器。亮色标记只表示本地关联图中与入口记录直接相连的记录；空日仅表示无记录。年轮不改变正文、筛选、排序或备份。三维画面可以暂停、展开或收合；画面不可用时，月份、日期和记录的文字导航仍可使用。真实设备与长期性能验收尚待完成，见[年轮验证记录](docs/current/celestial-note-wheel/verification.md)。

视觉层次与平面/立体节奏参考 MIT 授权的 [zaoxu001/celestial-wheel](https://github.com/zaoxu001/celestial-wheel)；晴笺使用自己的真实日期和记录模型，不引入原项目的术数内容。

旧「3D空间」入口及其主题空间、积累轨迹、空间外观已从当前源码移除。记录年轮、二维关联图、记录时光与独立伙伴页仍可使用；本次没有删除笔记或清除旧版偏好数据。

桌面窗口使用与晴笺主题融合的自绘标题栏，保留拖动、最小化、最大化/还原和关闭。主导航新增独立「待办」页，可添加、编辑、完成及删除带日期的事项；删除后可短暂撤销。待办分别保存在浏览器本机存储、桌面 SQLite 和 JSON 备份中；桌面数据库即使为空也以自身数据为准。普通记录不会自动进入待办。

导入旧版 JSON 备份时，记录和账目按备份替换，本机待办保留并显示提示；新版备份包含 `todos` 字段时，待办也按备份完整替换，包括空列表。

浮层伙伴新增「打开记录」快捷入口，沿用现有快速打开；「今日待办」可主动查看今天及逾期未完成事项。有事项时每天首次在应用内提示一次，全部摘要留在本机。奶龙及吉伊 3D 模型尚无明确产品再分发授权，本轮继续使用现有 SVG 角色。原生窗口交互仍需实际验收。

待办页在桌面宽度为右下角伙伴预留操作空间；窄屏保持全宽。该布局仍需原生窗口复测。

## 运行

```bash
npm install
npm run dev
```

浏览器访问终端显示的本地地址。

原生桌面开发版：

```bash
npm run desktop
```

生成 Windows 安装包：

```bash
npm run desktop:build
```

一次执行前端构建与 Rust 检查：

```bash
npm run check
```

## 原生端与 AI

桌面端使用 Tauri 2 + SQLite（WAL 模式）存储数据，数据库位于应用数据目录。AI 功能使用官方 `deepseek-flash` 模型，即 DeepSeek V4.1-Flash；模型名和 API 地址不会放在前端。

0.5.4新增顺序与置顶的兼容元数据，旧记录默认未置顶，备份仍为version1完整数组。迁移后不要使用旧EXE写回数据库：旧版整库保存会丢失新增排序和置顶元数据。没有自动降级恢复；操作前保留备份，详见[兼容与回滚边界](docs/Note.Ordering.md)。

首次启动桌面端时，程序会从 `%USERPROFILE%\.config\opencode\opencode.json` 的 DeepSeek provider 迁移现有密钥至 Windows 凭据库 `deepseek_api_key.com.zxl.qingjian`。密钥不会写入本仓库、SQLite 或浏览器本地存储。只有在用户向“晴笺 AI”提交问题时，相关的本地笔记/账本摘要才会发送到 DeepSeek API。

编辑器直接展示最终排版，不会向用户暴露 Markdown 或内部格式标记。底层仍保存安全、可迁移的纯文本，并兼容已有记录。
