## 免费试穿与穿上

当前 Web 源码可从主导航「伙伴」或设置「挑选装扮」直接打开本机免费装扮铺。已收起小伙伴时也能进入装扮页，不擅自重新显示浮层；伙伴页隐藏小伙伴。选择角色、配色、头饰、配件或一份搭配，大展示立即试穿；角色和搭配卡的 SVG 缩略图始终静态。装扮均可直接选择，不需要支付、账户或道具库存。

| 选择 | 当前选项 |
| --- | --- |
| 伙伴 | 晴小团、奶龙、吉伊、小八、乌萨奇 |
| 配色 | 云朵原色、薄荷晴天、蜜桃晚霞 |
| 头饰 | 不戴头饰、画家帽、星环 |
| 配件 | 不戴配件、柔软围巾、蝴蝶结 |
| 搭配灵感 | 云间画家、薄荷漫步、晚霞星愿 |

晴小团的配色会改变身体；其他角色保留本色，配色用于装饰。选择搭配只组合配色、头饰和配件，保留当前试穿角色。

- 「穿上这套」是应用并保存：记录页小伙伴、伙伴页大展示和记录时光伙伴随后使用同一已应用角色和装扮。再次穿上同一套也可以重试保存。
- 「撤销试穿」回到最近已应用的装扮，不写入存储。
- 「恢复原装」把配色、头饰和配件恢复默认，保留当前试穿角色；这是一次预览，仍需穿上才应用。

试穿与已应用值不同才显示「试穿中」；相同显示「当前装扮 · 已穿上」。离开宠物展示会丢弃未应用的试穿；已穿外观由App保留，不随试穿变化。✅ 工作区月历伙伴已接同一已应用角色和装扮，试穿草稿不会传入月历。日期摘要、写记录/回今天、隐藏与局部暂停仍由月历控制；月历画像只在自身与宿主许可内播放待机，不新增拖动或招呼计时器。

## 角色与动作

五位伙伴分别绘制身体、耳朵、尾巴或手脚，以SVG渐变呈现柔和体积。晴小团保留原始默认身体；奶龙与三小只为指定角色的代码重绘，动作由本项目设计，不是官方动画或真三维模型。

| 角色 | 轮廓与颜色 | 待机（idle）与招呼（happy） |
| --- | --- | --- |
| 晴小团 | 原创淡紫/青色团子、短耳 | 呼吸和轻摆；轻触后招呼。独立桌宠走路时按位移方向转身，动作以 0.28 秒交叉淡入，休息姿势只播一次 |
| 奶龙 | 黄橙大头、突出圆嘴、绿黑眼、白肚皮、短臂足与尾巴 | 肚皮轻起伏、摇摆；开心跺脚和欢呼 |
| 吉伊 | 白色身体、短圆耳、粉脸颊 | 轻晃与耳部动作；害羞挥手 |
| 小八 | 蓝耳、蓝猫纹与猫尾 | 探头和摆尾；摇爪与点头 |
| 乌萨奇 | 米黄身体、长耳 | 轻弹与耳部动作；跳起和欢呼 |

大展示可轻触、打招呼、休息或唤醒。记录页小伙伴可拖动、轻触、收起；设置页可重新显示。角色切换会取消当前拥有的拖动和短时招呼反馈，保留小伙伴的位置与休息状态；大小展示分别拥有本次会话的交互状态，只共享已应用外观。

## 本机保存与失败提示

宠物外观使用独立`luma-pet-appearance`键，保存角色、配色、头饰和配件。默认是晴小团、云朵原色、无头饰与无配件。显示偏好仍使用原`luma-pet-visible`键，位置和心情只在本次会话保留。旧空间外观键`luma-spatial-appearance`不再读取或写入；为避免擅自删除既有本机偏好，升级时也不清除它。

只有「穿上这套」写一次宠物外观键。保存成功后刷新或重启按本机偏好恢复；保存失败时当前会话仍穿上新装扮，并明确提示未保存，刷新或重启会回到上次成功保存的外观。试穿、撤销与恢复原装不写入本机偏好。

读取缺失、拒绝访问、非法JSON或字段不符时使用完整默认值，不纠正或覆盖原存储。此处理只覆盖新增外观偏好；App既有主题、固定标签和显示偏好的原存储访问未在本轮改写，不能据此声称整个应用在存储全面拒绝时可用。

宠物不读取笔记，不发送AI内容，也不改变SQLite、记录格式、排序或JSON备份。没有角色经济系统、联网商城或新增业务数据迁移。

## 动态与可见性

自动动作需要动态许可、页面可见、窗口有焦点和业务可操作。关闭动态、系统减少动态、休息或拖动时，身体及耳、尾、爪、肚皮等子层都停止；大展示光晕也按同一许可停止。选项缩略图不播放循环。

关闭动态或减少动态后，轻触、休息/唤醒和装扮操作仍可用；失焦、后台、弹层接管、隐藏及角色切换会取消拥有的手势与短时反馈，不在恢复后续接旧拖拽。休息只控制该展示的自动动作，未被恢复焦点覆盖。

浮层小伙伴在设置页、伙伴页、二维关联图页、记录时光页及弹层接管时隐藏。工作区月历画像还受局部暂停、隐藏、系统减少动态、后台、失焦和宿主弹层许可限制；恢复焦点不覆盖局部暂停。未传共享画像时保留原机器人回退。历史 0.7.0 Windows 体验包曾包含宠物和空间外观；当前工作区已移除旧空间。
