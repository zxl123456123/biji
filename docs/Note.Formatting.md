# 记录排版与起笔模板

## 当前能力

正文可选插入一处原创晴小团块：编辑区在不可编辑块内显示三维模型，阅读卡片、拖拽预览、记录时光和图详情显示静态形象。持久格式仅为独占一行、代码围栏外的 `[[pet:xiaotuan]]`；第二处、未知或转义写法维持字面文本。搜索和复制采用可见名称，装扮跟随当前衣橱但角色固定晴小团。工具只在普通正文折叠光标位置尝试插入；隔离浏览器已实测删除、撤销和重做，真正的中文输入法组合事件与 Windows WebView 尚未现场验收。

✅ 编辑器提供正文、标题、小标题、粗体、斜体、无序列表、有序列表、引用和行内代码。行内代码需要选中同一段的非空文字；跨段及已有代码选区不启用。日记、会议纪要、阅读随记只在全新的空白记录中出现，恢复草稿或编辑已有记录时不提供覆盖入口。模板是普通可编辑正文，标签、日期和完成状态不因排版而重置。

✅ 草稿状态独立于静态快捷键提示，保存按钮仍为主要动作。工具显示选区状态、键盘焦点与可用边界；正文焦点采用较柔和的圆角内圈。中文和英文斜体在编辑器与预览范围允许字体合成，保留主题配色。

## 格式边界与职责

`noteCodec.ts`负责有限块/行内语义、字面量编码、安全HTML与纯正文。`noteFormat.tsx`负责活动DOM采样、编辑回填和React安全节点；`noteText.ts`复用同一语义供图谱和查找使用。用户看到的是排版，笔记和草稿仍保存可迁移的纯文本，没有新增数据库/备份schema，也不持久化任意编辑器HTML。

已有颜色、字号和围栏代码继续兼容。粗体与斜体可以组合；代码中的标签符号、反斜杠、HTML样文字和格式符号保留为代码内容。`tagsFor`和`withoutTags`使用同一代码识别，只有代码外的标签参与普通标签处理。未知HTML作为文字展示。

空列表项、标题和全空引用可在编辑时暂留，保存不输出无字格式标记。标题/引用按既有标签规范化后的正文资格决定是否生成前缀，只有标签时仍保留原标签序列；有字块与代码内容保留。引用中的空行保存为空白分隔。普通字面符号仍按文字处理，不通过吞掉所有符号来隐藏错误。复杂外来嵌套排版可展平，本轮没有承诺任意HTML粘贴无损。

新增格式应同时验证活动DOM→纯文本、编辑回填、安全预览和正文抽取，不能只增加工具按钮。

## 原生编辑与撤销

编辑DOM和撤销历史由浏览器持有，输入期间不由React反复重写正文。格式后同步采样，提交时再次读取活动DOM；输入法组合期间不执行格式或快捷保存，保存后阻止草稿effect复写。

鼠标工具保留有效活动选区；键盘工具仅恢复仍连接且属于当前编辑器的选区。列表命令可能替换文字节点，光标修复只在折叠选区、节点仍属于编辑器或命令后文字完全相同的替换节点上恢复原位置，不建立全局光标或历史框架。

回填引用的“正文”使用一次原生outdent退出；转为标题/小标题先退出引用再设置块级格式，因此有两个原生撤销步骤。模板插入仍为一次原生命令，可一次撤销。[MDN原生命令说明](https://developer.mozilla.org/en-US/docs/Web/API/Document/execCommand)用于确定编辑/撤销边界；具体浏览器行为以实际验收为准。

代码的最大等长反引号与空格边界参考[CommonMark代码跨度](https://spec.commonmark.org/0.31.2/#code-spans)，保留既有单反引号空格兼容；本项目没有实现完整CommonMark。局部斜体合成依据[MDN字体合成说明](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/font-synthesis-style)，字形结果另以本机实际截图核对。

## 验证与限制

✅ 本轮实际检查连续中英输入、两种粗斜顺序、列表末尾/中间光标及续写、键盘工具、原生撤销重做、格式后立即保存、模板/草稿/日期/标签、卡片/图详情/再次编辑和浅深窄屏。过程中的失败及复检见[本轮记录](current/composer-writing-modes/verification.md)，新制品与最终命令见[0.5.2验证](Release.Verification.0.5.2.md)。

⛔ 完整原生中文IME、macOS、读屏、触屏、安装卸载及GPU/长期预览稳定性仍未验收。浏览器实测和纯函数测试不能证明全部平台没有bug。附件、表格、嵌套列表编辑、通用模板引擎和编辑器插件系统未新增。
