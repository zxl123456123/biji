- **具体内容**：LW `:50` 要复用“原App状态/回调”，`:119` 只说明 space 外层接 NoteFilters；未定位/展示 `selectTag` 的导航变更。真实 before `src/App.tsx:95` 为 `nav(view === 'graph' ? 'graph' : 'all')`，`:200` 的 TagPicker 直接使用 `onTag={selectTag}`。

### D2：空间正文搜索缺少顶栏已有视图条件（阻断）

- **具体内容**：LW `:50` 写“原输入query仍由现有全局搜索入口控制”，但未定位/展示顶栏搜索条件。真实 before `src/App.tsx:190` 仅 `all/trash/graph` 呈现绑定 query 的输入；其他视图的“查找记录”按钮执行 `nav('all')`。

- **建议恢复动作**：planner 在 S3 明确顶栏既有显示条件锚点与 space 中复用 query 输入/清除的目标规则，保持旧入口；补入片段及 root “在关联/时间视角输入和清除搜索、不离开空间”的验证。宠物子视角与记录搜索的呈现策略一并按既有受控 mode 写清即可，不扩大功能。
