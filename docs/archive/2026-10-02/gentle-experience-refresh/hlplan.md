# 晴笺 0.4.0 最小 MVP 高层方案

日期：2026-10-02。权威范围为 `clarifications.md` 的“完整实现基线”；承接用户纸感 A、能力优化及“继续开发并构建 exe”的授权。本文是待评审方案，不表示功能或性能已经通过验证。

## 1. 目标与非目标

交付可用的本地记录闭环：所见即所得写入、草稿继续、保存/编辑、查找与精确标签、未完成筛选、显示文本复制、删除撤销/回收站；本月账本统计、分类和流水一致。纸感浅深主题、窄屏、编辑器、设置与 AI 使用同一视觉语言。背景发光节点连线表达轻微纵深，允许关闭，遵守减弱动效与后台状态。产出 Windows 程序 EXE，尽可能产出 NSIS 安装 EXE。

不新增关系图、笔记收藏/历史字段、月份切换、排序选项、附件、同步、全文索引或通用插件体系；不更换存储和编辑器。每个交付项对应基线目标 1–3，未加入无来源能力。

## 2. 总体思路与数据契约

沿已存在的职责边界做有界整理，不建立大型目录体系。应用编排继续拥有笔记/账目、导航、筛选、主题、弹窗及既有持久化触发；视图、编辑器与 AI 按现有 props 边界展示和操作。筛选与月份统计是纯计算；编辑格式转换继续保持受限安全纯文本；装饰 Canvas 独立拥有帧数据和生命周期。

```text
应用状态 → 纯计算 → 记录/本月账本视图
编辑操作 → 既有保存路径 → 浏览器 / Tauri SQLite
主题与动效偏好 → 独立 Canvas → 装饰像素
用户主动提问 → 既有 AI 桥接
```

Canvas 不读取笔记内容，不连接笔记 ID，不逐帧写 React 业务状态或存储，且不接收点击。背景的随机连线不能宣称为知识关联或真实四维数学功能。产品版本建议 0.4.0；备份 `AppData.version` 仍为 1，Note/Transaction/草稿字段、旧格式兼容、SQLite schema 与 AI 摘要共享边界保持既有契约。动效偏好属于本机外观偏好，与主题同类，不添加到笔记模型或备份。

## 3. 关键决策与备选

| 决策 | 采用 | 备选与取舍 |
| --- | --- | --- |
| 组件与状态 | 复用 App 编排和 props 边界，只提取本轮确需维护/验证的职责；结构整理与行为修改分别组织 | 全局状态库、repository/事件总线扩大修改面，当前规模没有收益证据；完全继续压缩内联则难以验证新增筛选和动效隔离 |
| 查找与便捷操作 | 文本 query、精确标签、全部/未完成分别作为 UI 条件；纯计算组合，仍用现有字段；快捷键限定上下文 | FTS/高级表达式需要中文分词与新交互验证；全局 Enter 保存容易冲突。Ctrl/⌘+K 定位记录查找，编辑器 Ctrl/⌘+Enter 保存，保护 composing、重复事件与空内容 |
| 发光连线 | 小规模原生 Canvas 2D：节点明暗/大小/缓慢位移和轻微视差；明确节点/连线上限及生命周期 | CSS/SVG 更适合固定拓扑；动态近邻连线会增加 DOM 更新。tsParticles 有成熟选项但本轮需求小；Three.js 增加 WebGL、资源和设备兼容成本。采用 MDN 的限像素/绘制预算，不造通用粒子引擎 |
| 视觉与编辑器 | 集中基础色、文字、边框、间距、圆角与阴影 tokens，浅深主题替换值；复用弹窗边界落实可用宽度、焦点、关闭与恢复；触屏/键盘动作可发现 | 继续追加同名 CSS 补丁难以维护；更换完整设计系统或大型富文本编辑器超出 MVP。软背景配清晰正文，不以低对比度换柔和 |

显示文本复制采用与受限展示语义一致的结果，不复制 Markdown/颜色字号内部标记；剪贴板失败明确反馈。草稿提示只能说明本机草稿状态，不能冒称正式保存或 SQLite 已完成。

## 4. 风险、未决点与验证

- 研究 U1、C-U1/C-U2 的视觉与首轮范围由最新基线关闭；“4d”采用装饰纵深解释，交付描述必须准确。U5 由本月统一口径关闭设计范围。
- U2/U3 仍需实现后真实浏览器对照：弹窗宽度、深色预览、窄屏账本、选区、连续输入、保存/回填、IME、快捷键和焦点。纯函数测试不能替代编辑器手测。
- 动效以桌面最多 24 节点/60 条可见线、窄屏 12/24、目标 30fps、DPR ≤1.5、内部像素预算为低层上限候选；关闭/系统减弱/hidden/卸载均停止循环，恢复重置时间，StrictMode 不产生重复循环。CPU、查询延迟及包体预算引用补充研究，实施后测量；未测项明确留空，不宣称达标。
- U4/C-U4 的 Windows 缩放、旧数据库、真实 IME/GPU 证据不足时如实报告。Web 构建成功和 Rust 0 用例不等于无 bug。既有导入/损坏回退/桌面双保存风险维持范围外清单，不顺手改存储。
- 原始 App/store/styles 修改保留，快照位于 `%TEMP%/qingjian-pre-mvp-20261002`；不恢复现场、不混入未知工作提交。NSIS 历史组件下载失败，当前必须实际重试并记录结果；失败时交付程序 EXE，MSI 单独标识。

## 5. 向低层方案的拆解指引

1. 分开组织现有职责整理与功能/样式改动，逐项建立基线→实现→验收追溯；无需新增大型目录层级。明确精确标签比较规则、筛选组合/清除、场景新建、复制文本语义、草稿提示及各弹窗快捷键的焦点边界。
2. 明确本月纯计算的时区/日期边界，以同一交易子集驱动摘要、分类和流水；不改变 AI 请求范围。定义有意义的近似标签、已删除/完成、组合查询与跨月/跨年测试及运行命令。
3. 把 token 覆盖、弹窗尺寸/滚动、对话框可访问性、深色/窄屏/触屏、动效上限与停止清理落到可实现精度；对受限格式兼容和现有数据安全路径给出真实浏览器回归清单。
4. 版本协调锁定 `package.json`/`package-lock.json`、Tauri 配置和 Cargo 包元数据/锁文件为 0.4.0；不把备份版本改为产品版本。主代理执行 Web/Rust 独立验证、Windows 构建、EXE 文件/哈希与可行启动检查，生成当前发布证据。
5. README、CHANGELOG、Project.Progress 同步实际能力：当前已无今日/明天/准备中独立视图，也无颜色/字号编辑入口；快捷键需以本轮实现为准，旧格式展示兼容仍成立。保留历史版本记录，不能把旧发布结果当本轮验证。低层方案、实现报告、独立实施审查和发布证据齐备后再归档。

无新增跨功能事实。
