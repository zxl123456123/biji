- 当前桌面全量保存两张表、正文修改后整图重新提取特征；优化时需要独立验证数据安全与关系结果等价。
- 保留React、Tauri、SQLite与D3 Canvas/Worker架构；不以竞品宣传或历史Node计时证明新界面流畅。
