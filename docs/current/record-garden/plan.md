## 目标

在独立分支 `codex/record-garden` 做可交互的记录回顾页，让用户看见哪些天有记录、记录数量的节奏，并由一个克制的像素机器人提供当日回顾入口。

## 可验收的范围

1. 月历、热力格与立体记录柱使用同一月份及所选日期；可翻月、回到今天、点日期查看记录并打开原编辑入口。默认以本机创建日期统计，可切换为记录归属日期（指定日期优先，缺省取创建日期）；不把修改时间冒称完整每日活动历史。
2. 每天显示数量、所选日期和今天，月摘要显示有记录天数/记录总数。回收站记录不参与；空月、闰月、跨年、时区和未来指定日期有明确行为。数量表示记录数，不是生产力评分。
3. CSS 3D 记录柱按日历顺序显示每日数量，保留日期按钮和文字计数；提供平面切换、固定镜头及轻量角度控制。无自动镜头飞行、不改现有 D3 关联图、不引入 Three.js/WebGL 或外部模型。
4. 自绘 SVG 像素机器人显示所选日期的记录/未完成数量，提供回到今天、写记录入口，可隐藏。只使用本地派生数据；无自动 AI 请求、通知、强迫打卡、养成数据或新 schema。
5. 支持浅深色、390px 窄屏、键盘操作、系统减少动态效果、显式暂停和后台暂停。新增样式全部限定在功能组件下。
