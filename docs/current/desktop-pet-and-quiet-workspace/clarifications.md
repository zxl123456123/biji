## 头脑风暴决策

1. 核心目标为实际 Windows 桌宠和简洁笔记工作区；正文插入功能方向被用户否定。
2. 独立桌宠使用现有 Tauri 的透明小窗口，与主笔记窗口分开；主窗最小化不暂停桌宠。沿用主窗关闭即退出应用的习惯，不新增托盘常驻、开机自启或后台服务。
3. 先加入有限的自主活动：待机、短距离活动、休息、轻触反馈；实用连接限已有快速记事和到期待办。不新增养成、商城、另一套待办或自动 AI 网络活动。
4. 保留已确认的原创晴小团轮廓。其他四角色改善现有本机 Blender 初模的圆润度、面部分区、眼神及动作，在新的 refined 候选目录保存，旧文件保留。通过忽略的本机资产进入个人 Windows 构建；不上传这些第三方模型到公开仓库。
5. 撤掉正文插入按钮与正文 WebGL/嵌套 root。旧指令仅兼容为普通短文字“晴小团”，编辑保存仍能保留其原指令、可整块删除；不批量改写现有笔记，不展示内部格式。
6. 界面主路径保留记录、搜索、待办和账本。导航把记录时光/关联图/伙伴收进可发现的次级入口，合并标题栏与顶部品牌区域；移走桌面端内嵌宠物面板，撤重复的大起笔区域和说明。滚动仅作用于内容区域，主题滚动条保持键盘、鼠标和触屏操作。

**用户确认**：✅ 核心问题、开发授权及桌面活动位置已由上述原话确认。窗口关闭习惯、首版动作集合及界面实现形式是 coordinator 在授权范围内的最小实现选择，不伪称逐项用户问答。具体方案需独立审查。

## 完整实现基线

### 目标锁

1. 五角色个人本机三维模型用于桌宠替换；Windows 独立透明伙伴在主窗最小化后仍可见、可拖动和自主活动，并能打开已有记事/待办。
2. 截图指出的标题栏色块/分割和粗全页滚动条消除；首页重复信息与入口减少，首屏优先显示真实记录和核心操作；无新增正文宠物入口或画布。
3. 主窗口继续是笔记/账本/待办唯一保存所有者；旧数据和草稿保持，新 EXE 实际路径/版本可核查并在原生窗口展示效果。

### 反目标

- 不继续扩展正文宠物、商城、投喂数值、宠物聊天或与现有任务重复的数据系统。
- 不在 pet 窗挂载整 App，不写回旧业务快照；不自动向 AI 上传笔记、监听全局键盘或分析其他应用。
- 不用 Web 截图或文件版本号冒充原生透明、最小化存活、自主活动和模型质量验证。

### 范围与实现关系

- 不改 SQLite schema、备份版本和 identifier。新增的桌宠读能力只读取必要待办摘要，工作流动作回到现有主窗入口。
- 公开源码支持原有 SVG 回退及可选的本机模型映射；个人构建需要明确资产来源、哈希与忽略路径。装扮若对本机第三方模型不生效，不显示虚假的可用控制。
- 短距离移动限制在所处显示器工作区域；交互、休息、减少动态或隐藏时取消自有移动/动画，不抢输入焦点、不覆盖整个桌面的大透明区域。
- 旧正文标记依然按受限 codec 回填和往返，不进行全库清除；阅读形象变成普通短文字，现有正文其他格式和元数据保持。
- 分成界面/旧正文收敛、模型细化、独立桌宠三个清晰工作包；实际差异超约一千行时按逻辑提交拆分，避免混入重构。

### 风险边界

- 原生透明、窗口拖动/定位、DPI/多屏、后台定时器和关闭清理须以实际 EXE 验证。无法输入的环境组合只能记未测，不自行宣布跨设备合格。
- 模型改良在本机候选中展示真实前/侧/背和桌面尺寸；视觉满意度由用户决定，不凭 GLB 格式测试称最终造型定稿。
- 不覆盖正在运行的旧 EXE；保留旧安装文件与版本交付目录。新版本计划 0.9.0，取代未完成验收的 0.8.1 候选作为本次交付来源。

### 验证责任

- impl：每包报告实际 diff、fresh npm测试/build（必要 Rust测试/check）、模型 Blender 导出/重导与格式/动作证据，保留所有实际失败。
- reviewer：检查实际代码、当前基线与命令，独立审查唯一保存所有者、事件/窗口/计时器清理、旧正文往返、资产隔离和界面可用性。
- coordinator：实际浏览器连续输入/选区/保存回填/快捷键/深色验证；最终 EXE 路径/版本/SHA、原生双窗/透明/最小化/活动/拖动/实用入口/收起恢复及数据库前后旧字段比较。只能陈述真实观察。
- 证据保存于本目录 verification.md 与相应实施/审查报告；制品、备份和截图在 src-tauri/target 忽略目录，生成物不提交。
