## 原始需求

> 还有需要优化的地方，关于账本那里，需要清晰一点，我现在记录本月的资金，记不了之前的，最好有个入口能够记一下每个月什么时候，每年也追随上，然后就是我现在的总资金记录，总资金的记录会随着我的记录，就是消耗，增加这些来自适应变化，这样我能够时刻看到我的钱的变化。但是这个最好隐蔽一点，我点进账本之后，还要有个入口才能点进去。另外这个页面布局再优化好看一点清晰一点之类的。

## 当前范围

- 账目可选择实际发生日期，支持往年、往月补记与编辑。
- 账本按年份、月份查看，提供年度汇总与十二个月回顾。
- 清晰区分收支统计、分类分布和流水，适配浅深主题与窄屏。
- 保持浏览器、SQLite、JSON 备份以及旧笔记、附件、待办和原账目的兼容。
