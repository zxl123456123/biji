# 3D 视图与关联图交互调研

日期：2026-10-05。只读调研；本文件提出限定范围的前端建议，没有修改实现，也不作为已验收结论。任务阶段及正式 Gate 由 coordinator 维护。

## 已核对的实现事实

- `src/NoteGraph.tsx`：当前 2D 图投影全部匹配 UUID；点选后弱化非邻居，实线表示共同标签，虚线表示词面推断；旁栏有全文、标签、每条关联依据、编辑/定位/回收站入口。文字选择器仍列全部匹配记录。尚没有「当前记录的直接关系」范围或关系类型筛选。
- `src/SpatialNoteMap.tsx`：3D 的关联星图也投影全部匹配 UUID，旁栏重复全文、标签及关联依据；分组色标仅静态展示前 6 个主题组。外观配置默认在图前完整展开。
- `src/spatialLayout.ts`：3D 星图按既有主标签/词面组摆放，组内位置由 UUID/槽位确定；这不是语义距离，也没有第二套关系算法。时间层的横轴是创建时间，纵向为分组，纵深为完成状态，未知时间保留。
- `src/spatialScene.ts`：已有点选高亮线、定位选中记录、适配全部、旋转/缩放、后台/失焦暂停和按需绘制。点选时所有底层关联线仍画出。已有自动缓慢旋转和流光，不能把这些称为任务信息。
- `src/App.tsx`：`openRecord/locateGraphNote` 已有 UUID 定位关联图路径；3D 现有 `onOpenGraph` 仅 `nav('graph')`，没有携带空间选中的 UUID。
- `docs/Note.Graph.md` 与 `docs/Spatial.Experience.md`：关系来自共同标签/本地词面推断，只画部分边；图谱与空间均不得写笔记、SQLite 或备份；时间层明确使用创建时间而非计划日期。

## 本轮范围建议：同一份记录，两种明确用途

| 页面 | 用户来这里做什么 | 首要交互与结果 |
| --- | --- | --- |
| 3D 空间 | 从全部记录看主题分布、跨主题连接和独立记录，再发现值得打开的一条 | 可点击的主题分组列表，显示记录数量/未完成数量；点击主题聚焦该组；「适配全部」返回总览。点选记录显示事实和正文，提供「查看这条的关联」携 UUID 转入 2D。 |
| 2D 关联图 | 围绕一条正在读的记录理解直接联系，沿依据继续阅读 | 全部/当前记录的直接关系范围；关系类型「全部/共同标签/词面推断」。选中后局部范围保留中心与所有符合类型的直接邻居；点击邻居可把它作为新中心。旁栏保留依据。 |
| 3D 时间层 | 从长期创建时间回顾笔记分布，结合主题定位旧记录 | 保留创建时间刻度和事实文案；不新增日/月日历面板、不展示计划日期、不生成日程、不接管正在开发的日历。 |
| 宠物 | 陪伴与角色互动 | 本轮不改 PetShowcase、宠物状态/外观/存储或相关导航；3D 记录探索不通过角色来解释。 |

## 清晰与舒适的具体优先级

1. 先把 3D 的标题/说明写成「主题概览，旋转发现」，2D 写成「从一条记录出发，查看直接关系」；保留中文、事实/推断图例和完整文字选择路径。
2. 3D 分组列表应显示真正的组名称与记录数，至少保留全部组的可访问入口。不能继续把「正文关联组」同名芯片当作可分辨主题；可显示序号并说明这是词面分组。分组结果仍采用现有模型。
3. 3D 外观使用可折叠 `<details>`，默认收起，让记录与图先出现。既有预览/应用逻辑可保留，不增加偏好字段。
4. 2D 当前记录范围只呈现中心的一跳邻居；切换关系类型后，中心仍可见，即使边数为 0；孤立记录的文字入口不能因关系类型消失。不要通过改业务搜索来实现局部范围。
5. 两个图切换时携选中 UUID；保留原搜索/标签/未完成共享筛选，不能为了跳转清除用户筛选。筛选移除选中记录时清空选择并说明当前范围。
6. 选择记录与切换类型只更改高亮或投影；镜头聚焦通过明确按钮触发。用户主动点击主题概览可明确调整镜头，仍遵守动态减弱与当前 policy。
7. 3D 聚焦组时只改变镜头及视觉强调，不改主标签、degree、原记录或关系证据。若做视觉弱化，非组记录保留淡背景，避免让用户误认为笔记丢失。
8. 可优先把 3D 的长期全图连线改为更低存在感，选中记录的直接边明确高亮。不要增加更多粒子、漂浮标签或同时常驻大量文字；可用稳定主题列表补足辨认。

## 最小验收回路

- 3D 全貌 → 主题聚焦 → 文字/节点选择 → 查看这条的关联 → 2D 中心是同一 UUID。
- 2D 全图 → 当前记录直接关系 → 两类关系切换 → 沿邻居阅读；中心、关系类型、事实/推断依据一致。
- 无关系、空正文、同名不同 UUID、未知创建时间仍可见且可打开。
- 减少动态/暂停后自动旋转与装饰流光停止；文字选择、点选、明确旋转/缩放/定位仍能工作。
- 浅/深主题和窄屏下：组名称、类型按钮和正文可读，图不挤压主要控件，折叠外观仍可访问。
- 未新增请求/AI 发送、SQLite/备份字段、日历状态、宠物状态；复用关系模型与现有 scene/scheduler。

调研只支持方案选择。产品实际舒适度、画布操作与桌面 WebView/GPU 行为仍需当前最终实现的 UI 验收。
