## 头脑风暴决策

1. 二维关联图回答“这一条和哪些记录有关、为什么”：保留全图，新增以当前记录为中心的一层/两层范围、共同标签/正文词面/全部依据过滤。当前记录是可变中心；选择下一条时明确更新中心，不创建固定中心加第二选择状态。孤立记录仍可查看，全图文字选择保留全部匹配记录。
2. 3D 默认回答“我积累了哪些主题、想去哪里看看”：关联星图改称主题空间；从既有分组派生可读主题导览、数量及未完成概况，点击主题聚焦、可回全部。独立记录合并导览项但保留每个 UUID；词面组不称人工主题或语义事实。默认不画全库连线，选中记录只画相关线。保留原度数与模型大小依据，关联分析不改。
3. 3D 继续提供创建时间的“积累轨迹”，明确用于跨时间的空间回顾；日历负责按天查记录，3D 不增加日期格子、计划/日程/统计副本。宠物页与五角色/装扮保持原样，不读取图关系。
4. 3D 找到记录后，以 UUID 打开二维局部图，保留搜索/标签/未完成；原请求 token/latest-record 验证继续复用。原 Ctrl K、原编辑与原保存不重构。
5. 视图层减少杂乱：3D 模型与氛围配置折叠但保留全部预览/应用控件；空间进入默认静态可操作，用户可开启动态。主题聚焦自动适配，外观预览不重置镜头/选择。二维保留清晰依据图例，浅深主题与窄屏控件可读。
6. 采用官方 Obsidian 全图/局部图的分工与 Three 按需绘制已有实现，不引入另一个关系引擎、图框架、网络或业务持久化。空间布局只读派生：主题聚焦尽量保留全集已派生坐标，重算选中子集 bounds；新控件写独立 CSS，不改宠物/日历/scene/models 核心。

**用户确认**：✅ 已授权自主完成常规可逆方案与实施；依据是当前开发指令及原空间聊天可核对的“自主开发实现…直接完成等我回来验收”。具体分工由 agent 判断，不伪称逐项用户选择。

## 完整实现基线

### 1. 目标锁

- G1：二维图可实际切换全图/当前一层/当前两层、依据过滤并显示准确可见数量；独立点、混合依据、搜索投影、失效/更新/删除与 Ctrl K 定位有可解释行为。节点和证据同源，只有当前记录范围按邻接扩展。
- G2：3D 实际主题导览/数量/未完成/组聚焦/全部恢复，默认线条克制且选中可辨；找到记录能携带 UUID 进入二维局部关系查看与原编辑。创建时间轨迹、宠物及外观配置继续可用，视图目的有直接中文说明。
- G3：清晰舒适的浅深主题/390px 显示；原搜索、UUID、编辑、格式、排序、存储和所有并发修改保留。根本轮真实 test/build、实际 UI 和 fresh review 绑定相同源码差量，失败与未测保留。

### 2. 反目标

- A1：不再用两幅密集星图重复表达同一用途；不把词面组/空间坐标称语义理解，不复制日历或宠物职责。
- A2：不新增业务 schema、存储/AI/网络/依赖、版本升级或安装包，不丢弃未知改动，不整包提交推送，不改并发宠物/日历/外观核心。
- A3：不新增 renderer、关系算法、RAF、图平台或全局筛选副本；不以测试/静态审查冒充 GPU 舒适度、原生 GUI 或多设备兼容实测。

### 3. 风险边界

空间遮挡、真实主题/窄屏舒适度由根实际浏览器检查；广泛 WebView/GPU/触屏/读屏、长期内存耗电、原生安装验收保留未测。共享文件变更前后必须核对输入快照与最新差异，只合并本轮片段。若发现无法安全合并，保留结果并交接，不覆盖对方成果。

### 4. 验证责任

- impl：纯投影/范围/证据/主题聚焦非变异测试，读取 actual output/exit；类型与构建。不得运行真实数据库、用户笔记写入、浏览器现场或自行提交。
- root：独立全量 npm test 与 npm run build（本轮 fresh）、浏览器使用独立合成数据验收二维各范围/依据/无关联/跨视图定位，3D 全部/主题/选择/相机/静态/模型配置保持，搜索/浅深主题/390px。原始日志和快照落 TEMP/qingjian-view-purpose-20261005；截图使用本聊天 visualizations 目录。
- fresh reviewer：未参与实施，读取真实 before/current 差量、原始根命令与 UI 证据、当前文档及基线；输出协议/业务结论。审查后代码修改需重新验证与 fresh 审查，证据缺失只能未验证。
