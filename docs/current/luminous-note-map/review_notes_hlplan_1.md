## 可行性与目标核验

已独立核对当前 App 状态/筛选/保存/删除恢复/编辑入口、types、recordTools、noteFormat、NoteComposer、store、desktop、AmbientNodes、CSS 布局及 package。当前仍是 0.4.0 侧栏单列和随机边缘装饰，源码确实支持“视觉改动保守”，没有缓存根因证据。方案的顶部导航、默认 2–3 列网格/日期模式、大约 65vh 真实图和主体多色，是可区别于旧工作台的结构变化，不再以候选 HTML 或装饰冒称脑图。

真实图集合由同一 selectNotes 派生且默认排除 deletedAt；模型在全部未删语料上构建，筛选只取诱导子图，可保留组色/IDF在查询间稳定。每条筛选笔记一个节点、孤立节点不丢失、等待更新仍用当前 ID 集合、失效选择清空，符合 G2。标签事实、词面推断与空间布局分工清楚；稀疏子集、桥接组与非语义准确的限制有明确产品说明。

D3 四个必要子包及 Canvas 是有理由的唯一选择，力导/zoom/drag复用成熟能力而非自制引擎。研究对 RFG2d 的暂停与 DPR 限制没有误用，其他三类路线的取舍与本轮规模/功能有关。版本/许可已有研究及 hlplan 内标注的 root 逐包核对回传；本 reviewer 未冒称重跑 registry 或实际安装兼容。真实依赖包体/生产 WebView/交互成本仍待实现测量。

## 风险及低层必须细化的合同

- **关系上限的定义**：D2 每节点两个标签/两个正文近邻应在 LW 明确为各通道选出的候选配额及最终无向边去重政策，说明接收到他人近邻后度数可否超过该配额；不能同时误承诺“最终度数≤2”和只做定向 top2。以全局≤4n及明确可解释子集验收，而非完全关系图。
- **正文与分组确定性**：把受限显示语义提取写成纯函数，保留颜色/字号/代码文字、不用 DOM/任意 HTML 构图；空正文不能因同哈希建立虚假相似。标签按文档去重计算出现频率，规范化、Unicode gram、短文本/高频/同分排序、哈希桶完全相同核验及关联组稳定键须有夹具。阈值0.32/0.55是已授权工程取舍，非相似质量已达标。
- **交互与生命周期**：D3 的模拟对象必须独立，不能 mutation 原 Note；坐标转换、Canvas drag/zoom竞争、drag结束抑制click、暂停/减弱时新节点可见且静态可选/拖缩，需明确实现锚点与验收。UUID位置/镜头缓存由工作台会话持有，不能因图组件卸载失去承诺的模式切换位置；仅首次或用户 fit 改镜头。
- **Worker 与失败**：HL 的版本响应/卸载取消和等待时不展示陈旧关系合理。LW 须给确切启用阈值/有界请求队列、旧响应排除、error/messageerror/不可创建时的非陈旧错误展示或有界回退；不能留永久“更新中”，不能以主线程无界回退掩盖性能失败。
- **可见持续动态**：冷却物理与持续光流分开正确；停止后仍有一次必要重绘和文字替代。hidden/卸载/编辑打开/减弱的优先级、恢复时间重置、旧监听/计时清理必须可核查。性能候选只能报告当前数值或未测原因，不承诺全部GPU丝滑。

这些是 HL 第5节已明确要求 LW 细化的实现/测试点，不要求新增产品决策，也不构成当前方向阻断。不存在必须引入新数据模型的风险；异常可关闭图回记录网格，但关闭不是满足脑图验收的替代成果。
