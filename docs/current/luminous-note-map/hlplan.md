# 炫彩记录工作台与真实关联图：高层方案

日期：2026-10-03。输入为本功能最新完整基线、README、research 和两份原始反馈。以下为正式唯一工程路线，尚未实现或验证。用户对聚类及成熟技术分析的授权已明确，无新增产品确认依赖。

## 1. 目标与非目标

G1：真实应用从旧侧栏单列改为顶部工作台导航与宽内容，默认桌面 2–3 列记录网格，窄屏单列；可切换按日期分组。主体可见多色光场、渐变边缘与克制丝滑动态，正文保持稳定底色与对比。顶部“记录 / 关联图 / 账本”入口直接可见，回收站与设置作为工具入口；不恢复旧今日/明天导航。

G2：关联图主区域占可用宽度和约 65vh 高度，窄屏仍有明确画布高度与展开式详情。每个筛选后的未删除笔记恰好一个节点；孤立记录保留。标签事实边与正文词面推断边可解释，支持选择预览、编辑、关联高亮、拖拽、缩放平移、适配全图，保存/建删/撤销/恢复与筛选同步更新。

G3：采用成熟布局/手势能力，派生计算、图局部坐标/镜头、Canvas 绘制和业务持久化分离；保留安全纯文本、草稿/回收站、唯一 notes 与既有未提交工作。独立评审、纯关系测试、真实 UI/动态证据与当前构建后交付新版本 Windows EXE。

不做远程 embedding、手工关系表/坐标持久化、完整语义模型、通用渲染插件、双引擎或自制物理引擎；不每帧构图/React setState/保存，不静默省略节点。随机装饰不得代替真实关系。当前弱视觉的代码证据支持设计保守，不能再归因于缓存。

## 2. 唯一工程路线与系统边界

采用 **d3-force + d3-zoom + d3-drag + d3-selection + Canvas 2D**，不装完整 d3。force 提供成熟模拟/碰撞/中心及分组吸引；zoom/drag 处理鼠标、触屏手势与成熟事件边界；selection 是绑定这两类行为所需的最小适配层。Canvas 自管缓冲、坐标转换、命中与颜色/流光，避免依赖无法公开约束的原始 DPR 属性。

运行依赖锁定 d3-force、d3-zoom、d3-drag、d3-selection **各 3.0.0 / ISC**；开发类型锁定 @types/d3-force **3.0.10**、@types/d3-zoom **3.0.9**、@types/d3-drag **3.0.7**、@types/d3-selection **3.0.12**，均 **MIT**。研究已核实 d3-force，root 在本阶段回传其独立逐包 npm registry 核对退出0，补齐其余版本/许可；本代理未冒称自行执行这些 registry 查询。首条多名称 npm view 只返回首包，root 随后逐包补核，不能把首条当全包证据。不写本地 `any` 声明绕过类型，锁文件保留传递依赖及许可；发布文档记录实际依赖组合与真实 gzip，不能拿 npm 解包量当包体。

```text
App 唯一 notes ──→ 未删语料快照 ──→ 本地纯关系模型（必要时专用 Worker）
     │                                  │
     └─→ 现有 selectNotes ──→ 当前节点 ID 集合 ──→ 模型诱导子图
                                                   │
                             独立模拟对象 + UUID 坐标缓存 + 用户镜头
                                                   │
                             D3 布局/手势 ──→ Canvas 真实关联图
                                                   │
                             选择 note.id ──→ 安全正文详情 / 原 NoteComposer
                                                   │
                             保存/删除/恢复 ──→ App 既有保存路径
```

复用 App 编排、selectNotes、安全格式与 NoteComposer；新增纯关系模型和图边界；主导航/网格是在现有视图基础上的明确结构改变。不修改 Note/AppData/SQLite/AI 契约，派生图、相似分数、节点坐标与用户镜头都不写数据库。D3 收到独立 `{id,…物理字段}` 节点及独立链接对象，永远不把 Note 或其数组直接交给会 mutation 的 simulation/link。

## 3. 四项关键决策与备选取舍

### D1：D3 子包与 Canvas，而非完整图产品

| 研究的五类路线 | 本轮取舍与许可依据 |
| --- | --- |
| D3 force + zoom/drag/selection + Canvas | 唯一采用。成熟力导与手势、可控 DPR/清理、适合小点与持续流光。代价是需验证命中/世界坐标转换，不能称比成熟组件更省开发。四个运行子包均 ISC、类型包 MIT，核验来源见上文 |
| react-force-graph-2d | MIT；已有点选/拖拽/缩放，是真正可行备选，不能用 pauseAnimation 误用淘汰。拒绝原因是研究源码显示双 Canvas 按原始 DPR 分配且无公开 pixelRatio 上限，可见静态交互仍有检查循环；本轮优先明确缓冲与彻底停循环控制 |
| Cytoscape.js | MIT；成熟 Canvas/图分析适合手工关系编辑。自动派生图不需要完整图查询/编辑模型，功能面与动态定制成本较大 |
| Sigma + Graphology | MIT；适合大图 WebGL、模型与 Worker 布局。引入多包/独立图模型/WebGL 程序与兼容成本，当前实际规模尚不足以证明需要；不默认 beta |
| React Flow / @xyflow | MIT；适合富 DOM 节点和手工流程。持续移动发光点不需要端口/节点表单，DOM/React 高频更新与目标不匹配 |

不保留第二套引擎，也不建 renderer 接口等待未来切换。若实测成熟 D3 适配不能稳定满足交互，属于方案缺陷回评审修订，不暗自另塞一个图组件。

### D2：本地词面稀疏关系，而非模型语义或全量成对图

关系模型在**全部未删语料**上构建，过滤只取当前笔记节点及两端都可见的边，保持 IDF、分组与颜色在搜索间稳定。标签沿当前 tagsFor 语法，标签只进入事实通道；正文使用受限格式的显示内容，保留颜色/字号中的文字、按 Unicode 字符提取 2/3-gram，再使用稀疏 TF-IDF 与余弦。借用成熟算法原则，不引入 Python、scikit-learn 或模型运行依赖，不声称懂同义/否定。

标签倒排表内按 UUID 稳定邻接骨架产生候选，不枚举大标签团的完全图；每节点保留至多两个标签邻居，边详情列出实际共同标签。正文用倒排 n-gram 产生候选，跳过高频无区分力特征，稳定选最多 64 个候选再算余弦；每节点最多两个正文相近邻居，初始阈值取 0.32，低层用短句/模板/中英混合等夹具核对。规范化完全相同正文另用哈希桶的稳定邻接候选，避免因所有特征高频而失去重复内容关联。

合并去重后边上保存两个通道的依据，事实边实线、只有推断的边虚线；并存时详情分别列明。边上限约 ≤4n，但**节点不截断**。此图为稀疏关系子集，详情说明候选/邻居限制与“词面相近≠语义相同”；不是全量相似检索或显式双向链接。

备选为所有笔记成对余弦或远程 embedding，前者稠密成本高，后者不符合本机低依赖范围。候选上限/阈值是可回归的工程取舍，允许按夹具与性能证据在 LW 明确调整，不能未经说明降低节点集合。

### D3：可解释主标签/正文关联组，而非默认社区引擎

有标签记录以**全语料出现较少的标签**作主组（同频按确定字典次序），体现具体主题而非都归入“生活”；全部标签关系仍可跨组。无标签记录仅在相互正文近邻且余弦 ≥0.55 的强边上形成连通关联组；其余保留独立节点。组名用标签或“正文关联组”，图例明确是词面推断，不能把力导位置称为唯一正确主题。组键与配色确定，文字图例/详情补足颜色辨识；同 UUID 保持位置，分组改变只温和重排。

备选为所有边连通分量（一个宽泛标签/桥接会合成巨大组）或 Graphology Louvain（额外依赖、随机/分辨率与稳定命名政策）。本轮先不引入社区引擎，力导仅负责空间排布，分组由上述纯规则决定。大正文关联组仍可能由桥接扩大，测试和详情需体现此限制。

### D4：可冷却布局 + 持续视觉，保留静态交互

布局可自然冷却，节点呼吸、细流光和多色主体光场提供持续动态；不保持高 alpha 让阅读目标一直漂移。选择高亮当前节点及真实邻居，详情给安全正文与依据、明确编辑入口。拖拽基于 d3-drag；缩放/平移基于 d3-zoom；Canvas 用统一世界→屏幕与逆变换命中。使用成熟 drag 的移动阈值/点击抑制能力，不能 pointerup 就直接编辑。另提供同一筛选集合的文字节点选择/预览入口，Canvas不是唯一访问途径。

同 UUID 内存位置与镜头跨内容/筛选/增删更新保留，缓存随工作台会话存续，记录/图模式切换不清空，不跨应用启动持久化。新增位置靠关联组，删除或隐藏移出当前图；恢复可重用短期内存位置。计算等待期间节点仍严格来自当前筛选集合，暂不显示可能陈旧的关系并标示更新中，不用旧模型漏掉新笔记或暴露已删内容。首次展示或明确“适配全图”才改变镜头，不在每次保存/筛选时自动 fit。选择项不再可见时清掉详情，不显示已删笔记。日期分组是网格展示模式，沿现有记录日期展示规则，不成为第二套状态导航。

用户暂停/系统减弱时停止持续物理与流光，但拖拽/缩放/选择可触发一次必要重绘；必要适配/拖拽采用静态/即时更新而非暗中重启动画。后台与卸载取消 rAF、simulation 与监听；前台按偏好恢复并重置时间。打开编辑器时停自动动态，已有选中详情冻结该节点避免点选漂移。主题/缩放/指针变化只更新绘制/图局部数据，不重算正文模型、不写 notes。

## 4. 三类关键风险、降级与验证责任

| 风险 / 研究 U 点 | 缓解与回滚 | 验证责任与结论限制 |
| --- | --- | --- |
| R1 关联质量与稀疏语义（U1/U4）：短句/模板、宽标签、桥接组可能误导 | 原始内容不变；事实/推断、稀疏规则与组名可解释。低层锁定可回归阈值/候选政策。功能异常可关闭图入口回记录网格，不删数据，不冒称图实现已满足 | impl 测 ID 集合相等、孤立/重复/标签大团/格式正文、确定性与原 Note 不 mutation；root 用隔离样例实际选中/编辑/建改删恢复/筛选并查看依据，reviewer 审规则和证据。无真实内容质量证据不宣称语义准确 |
| R2 主线程/Canvas与动态成本（U2/U3）：大正文构图、DPR、缩放命中、布局与绘制 | 计算只在语料内容/有效集合变化；长任务需要时用**一个专用有界 Worker**复用同一纯模型，响应带语料版本，旧响应丢弃/卸载取消。阈值和失败处理由LW实测合同落实，无通用任务框架。Canvas图容器尺寸、DPR≤1.5、buffer≤250万像素作为目标；可降低标签/发光/粒子频率，不能漏节点 | impl 纯计算/版本响应测试与生产 build；root 100/500/1000笔记隔离样例测构图/包体、实际DPR与拖缩、开关/hidden/StrictMode/减弱交互。研究p95构图≤300ms、绘制≤8ms、30–60fps、增量gzip≤25KB均待测，不把单函数时间当整UI丝滑 |
| R3 产品轮廓与回归/制品（U3/U5）：再只换颜色、手势与编辑冲突、丢失原工作 | 顶部导航+默认网格+大真实图是硬验收。保留已有12项/草稿/回收站/editor/本地安全；结构整理和功能分别组织；只回撤本轮图/UI补丁，不restore现场。旧0.4.0为历史，发布新版本一致元数据与新制品 | impl 自证纯模型/原12项/类型构建并完整报告；reviewer独立Gate2/ReviewImpl；root改前后真实项目截图、多帧持续效果、浅深/窄屏/日期模式/键盘/编辑验证与WindowsEXE/哈希/可行启动。IME/触屏/原生缩放/GPU缺实证列未验证；GitHub检索403/页面失败只作为已见检索限制，不编维护结论 |

所有失败/未测边界留存，测试/制品未核验前不宣称完成。没有新 schema 迁移；Git初始工作合并确认仍未获答复，只影响合并提交，不阻断实现与 EXE。旧导入/损坏JSON/桌面双保存问题保持范围外报告。

## 5. 下游低层规划指引

1. 拆清职责整理、主工作台/网格/日期、纯模型、D3 Canvas 与版本/验证工作包；不重写整个 App。对原组件 props/数据契约给具体锚点，唯一笔记源与图模拟副本必须可检查。
2. 按第2节已核实版本锁定四子包/必要类型与许可证；正文可见文本提取、候选稳定排序/高频政策、哈希桶、边合并、主标签及强边关联组给可执行规则和夹具。模型版本/过滤诱导子图/Worker阈值与旧响应合同不能留“按需优化”占位。
3. D3绑定、事件坐标、DPR、点击抑制、暂停静态操作、同UUID缓存/镜头/选择项失效、增删更新与全部清理给完整状态边界；只用实际需要的交互，不造多层手势状态机。
4. 顶部导航、2–3列网格/日期切换、大图及正文面板、浅深与窄屏给目标结构；色彩/光场必须主体可见，同时定义正文稳定底色、焦点与文字替代入口。持续效果用多帧真实项目证据验收，不能只给候选HTML或静态截图。
5. Gate1/Gate2 与实施审查、impl-safe/root承接证据明确分层；同步当前README/CHANGELOG/Project.Progress，保留0.4.0历史，选择新版本并重新构建 Windows EXE。性能候选要实际报告数值或未测原因，不能把所有设备丝滑当验收结论。

无新增跨功能事实。
