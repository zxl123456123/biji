## C. 已有 SVG、动作与政策事实

- 本次实际读取 `src/PetCompanion.tsx` 与 `src/pet.css`；PetPortrait 声明在 `PetCompanion.tsx:43`，旧报告该锚点当前已为43。
- SVG 共用固定240×230坐标，画像每实例以 useId 隔离渐变；大小展示都调用同一个 PetPortrait。
- `pet-body` 包含身体、耳、脸、肢体与叶片；目光层 `pet-gaze`、眨眼层 `pet-blink` 嵌套其中；外侧有阴影、光晕、闪光和睡眠标记。
- 当前 CSS 给身体4.6秒呼吸、眨眼6.3秒、目光11秒；happy 身体招呼为0.7秒两次，休息/拖动是静态身体变换。
- usePetBehavior 每个展示实例只有一个短反馈 timeout；tap 在1400ms后 settle，blur/取消会清除反馈并取消 owned 手势。
- 组件将 petPolicy 的 present/interactive/animate 分别用于展示、操作和自动动作；减少动态还有统一CSS覆盖。
- 名称、提示文案及 aria-label 当前写晴小团；新增角色需要与已应用角色一致，不能只换图后仍读出旧名称。

## D. 自主动作取舍与适配建议

以下动作来自本轮 clarifications 的项目自主设计，**不是从官方动画提取或复刻**，尚无实际视觉验收：

| 角色 | idle 表现候选 | happy 表现候选 | 主要独立图层 |
| --- | --- | --- | --- |
| 晴小团 | 保留现有呼吸、眨眼和目光 | 保留现有招呼 | 现有身体/目光/眨眼 |
| 奶龙 | 肚皮起伏与身体摇摆 | 开心跺脚 | 肚皮、脚与身体 |
| 吉伊 | 轻晃与短耳抖动 | 害羞挥手 | 耳、手与身体 |
| 小八 | 探头与摆尾 | 摇爪 | 头、尾与爪 |
| 乌萨奇 | 弹跳与长耳抖动 | 更明确的雀跃 | 身体与长耳 |

（推断）角色专属图层和 CSS 关键帧已足以表达上述有限差异；共享四态/policy/1400ms反馈可继续保留，不需要五套计时器或第二RAF。
（建议）先保持各角色独立轮廓，再对相应部位设置运动中心；不能把晴小团的固定脚底/眼部原点原样用于所有不同身体。
（建议）身体上的装备随身体运动，尾/耳/肚皮/爪保持自己的子层；独立动作不要覆盖休息/拖动的身体变换或遮挡识别特征。
（建议）自动动作全部受 animate、mood 和原政策约束；减少动态、休息、拖动、失焦及弹层期间仍能静态看清角色并执行原交互。
（建议）换已应用角色时清除前角色短反馈与 owned 手势，保留会话位置，不将前一角色招呼余时续接到新角色。
（建议）角色差异至少在idle/happy的部位、节奏或轨迹中肉眼可辨；颜色变化和同一关键帧改名字不能证明不同动作已经实现。
